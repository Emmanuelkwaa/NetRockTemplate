# Deployment

<!-- @init:if deploy=aspire -->
Production runs on Docker Compose generated by Aspire. The AppHost (`src/backend/NetRockTemplate.AppHost/Program.cs`) is the single source of truth for development and production.

```bash
# Write docker-compose.yaml and .env into ./aspire-output (images are not built)
aspire publish --project src/backend/NetRockTemplate.AppHost/NetRockTemplate.AppHost.csproj -o aspire-output

# Build the image and run the stack on the current Docker host
aspire deploy --project src/backend/NetRockTemplate.AppHost/NetRockTemplate.AppHost.csproj -o aspire-output
```

`aspire-output/` is git-ignored. The generated stack contains the Blazor app (built with the .NET SDK container support) and the Aspire dashboard.
<!-- @init:end -->
<!-- @init:if deploy=compose -->
Production runs on the single-instance `docker-compose.yaml` in the repository root. Aspire is used for local development only.

```bash
cp .env.example .env     # git-ignored; fill in every value
docker compose up -d --build
docker compose ps        # wait until frontend is healthy
```

The app listens on `HTTP_PORT` (default 8080). The image is built from `src/frontend/NetRockTemplate.UI/Dockerfile` with `./src` as the build context.

Put a TLS-terminating reverse proxy in front. To join an existing proxy network such as Coolify, uncomment the `coolify` network block and the `- coolify` lines in `docker-compose.yaml`, and remove the `ports` mapping.
<!-- @init:end -->

## Health check

- `GET /health/live` - the process is up (used by the container healthcheck). It is mapped by `MapDefaultEndpoints()` from ServiceDefaults.
